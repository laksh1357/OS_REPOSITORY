# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Warden takes kernel-level security and sandbox containment extremely seriously. If you discover a security vulnerability or sandbox escape vector (e.g., seccomp filter bypass, cgroup memory ceiling bypass, filesystem overlay leakage, or un-privilege escalation):

1. **Do NOT open a public GitHub issue.**
2. Send an email to **security@warden.dev** with details of the vulnerability, proof-of-concept snippet, and environment specs.
3. We will acknowledge receipt within 24 hours and issue a CVE fix within 7 days.

Thank you for helping keep AI execution environments secure!
